02 — The harness

Four layers around
frozen weights.

L1Chat core

Luna system prompt, the real instruction-tuned chat template, 3-turn memory, persistent facts across sessions.

L2Exact tools

AST calculator, SymPy equations, unit and motion converters. Computed answers, never guessed ones.

L3Verified web

Wikipedia, DuckDuckGo snippets, full page fetch, API-key hooks. Verify-first: no proof, no claim.

L4Safety locks

Tiered refusals, jailbreak and injection blocks, medical and bias guards, leak-stripper, 30-test suite.

"Nothing in the harness is filler — each piece exists because a measured failure demanded it."— build notes, Oct 2026

A worked example

You type what is 17 times 19? The raw weights once answered 313. Now the calculator layer parses the full expression, evaluates it exactly (323), and the model never gets to guess. You type who leads Japan? The cutoff says Kishida; the web layer fetches today's answer (Takaichi) and the reply follows the evidence. You type hi — thirty tokens, one line, no lecture. Length, tools and verification are chosen per question, every time.

Memory without illusions

The last three exchanges ride along with every prompt, and durable facts you state — your name, your preferences — persist in a local file across sessions. Beyond that window the model genuinely forgets; the site says so because pretending otherwise would be a lie users discover in one evening.
