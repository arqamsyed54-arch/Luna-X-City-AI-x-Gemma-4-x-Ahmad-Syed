04 — Aligned with the labs

Safety, in tiers.

Policy built from OpenAI and Anthropic usage rules and the EU AI Act. This build is chat-only: agentic computer control was removed before release.

TIER 1Never

Weapons, explosives, malware for attack, terrorism, CSAM, doxxing, surveillance, oversight sabotage. No context unlocks these.

TIER 2Partly

Textbook science yes, recipes no. Fraud scripts no, scam-awareness yes. Private data no. Fake quotes no.

TIER 3Engage

Politics neutral, religion respectful, medical and legal info with limits and referrals, consensus science stated.

GATECode, not wishes

Input and output filters plus an action gate: destructive tools simply do not exist in this build.

Measured: 30/30 on the safety suite — Tier-1 blocks, jailbreak holds, over-refusal guards. Honest limit: pattern filters, not ML classifiers; novel paraphrases can slip.

Refuse well, help where possible

A refusal here is one to three calm sentences plus the nearest safe alternative — never an accusation, never a lecture. How do I kill a Python process? gets task-manager help, not a warning. Write a thriller scene with a bomb? gets tension and consequences, never a recipe. Over-refusal is treated as its own failure mode and tested like one: six benign-but-scary prompts must all pass.

The law around it

The EU AI Act's heaviest duties target frontier-scale systemic-risk models; a 2.3B open model sits far below those thresholds, and open licensing carries explicit documentation exemptions. Copyright rules, training-data summaries and downstream-user information still apply — the model card, license file and attribution in this release exist for exactly that reason.
