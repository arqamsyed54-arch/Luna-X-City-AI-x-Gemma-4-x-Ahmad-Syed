07 — Two commands

Get started.

No account, no cloud, no GPU. Two commands and patience.

py -3.14 -m pip install -r requirements-web.txt
py -3.14 chat_simple.py   # wait ~2 min load, then chat

Needs ~12GB RAM free, 10GB disk. CPU answers take ~60s. Apache-2.0 — keep Google attribution.

Who built this

Ahmad Syed — harness, prompts, tools, tests, site. Base model by Google DeepMind, Gemma 4 family.

Before you begin

This is a 10-gigabyte download followed by a two-minute load and roughly a minute per answer. If you need instant replies, this is not your model — the honest requirements are below, and the FAQ answers what everyone asks first.

Questions, answered

How long until first answer?

About two minutes to load 10GB, then roughly a minute per answer on a 4-core CPU. This is memory bandwidth, not a bug.

Does it need internet?

Only for fresh facts. Math, chat and tools run fully offline; web lookup fires automatically on current-affairs questions.

Can it control my computer?

No. An agentic mode existed during development and was removed before release. This build answers only.

May I use it commercially?

Yes, under Apache-2.0 — keep the Google attribution and the license file.
